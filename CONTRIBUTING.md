# Contributing to CampusResQ

Thank you for contributing to CampusResQ!

CampusResQ is a collaborative project consisting of:

- Android Application — Kotlin + Jetpack Compose
- Admin Web Dashboard — React + TypeScript
- Shared Firebase Backend

Please follow the guidelines below to keep development organized.

---

## 🌿 Branching Strategy

Do not make feature changes directly on the `main` branch.

Create a dedicated feature branch:

```bash
git checkout -b feature/your-feature-name
